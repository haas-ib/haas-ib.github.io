WordPress plugin · on WordPress.org since Sep 2025

One Click Start

Time-saving tool for every new WordPress project.

Automates the setup chores every developer repeats on a fresh install — cleanup, core settings and bulk theme and plugin installs — and saves them as a JSON recipe you can import on the next site.

  • Deletes default posts, pages, comments and Hello Dolly
  • Sets permalinks, comment rules, search visibility and XML‑RPC
  • Bulk-installs a curated list of themes and plugins
  • Batch task engine with real-time progress, built to avoid timeouts
